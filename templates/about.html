About Plantus AI

A deep learning application for real-time plant disease detection

PlantusAI uses Convolutional Neural Networks (CNN) with MobileNetV2 transfer learning to identify plant diseases instantly from a photo. Built to help farmers and gardeners catch plant health issues early and accurately.

95%+ Validation accuracy
38 Disease classes
70k+ Training images
<500ms Response time
🛠️

Tech stack

Backend Flask · Python 3.11
ML TensorFlow 2.16 · Keras
Frontend HTML5 · CSS3 · JavaScript
Image processing OpenCV
Deployment Docker
Architecture MobileNetV2 + Transfer Learning
🚀

Features

Real-time plant disease detection
Upload image or use camera capture
Confidence scoring per prediction
Top 5 predictions with probabilities
REST API for integration
Responsive web interface
